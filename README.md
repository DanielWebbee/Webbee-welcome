# Webbee Welcome

Landing page for Webbee Digital (outsourced SDR / B2B lead generation), in the style of explee.com.

Single static file: open `index.html` or deploy the folder to any static host (Netlify, Vercel, GitHub Pages).

## Before going live
- Replace placeholder content marked with `data-edit` (hero stats, client results, testimonials).
- Edit the `CONFIG` object at the bottom of `index.html`: `bookingUrl`, `formEndpoint`, plans and prices, FAQ, legal links.
